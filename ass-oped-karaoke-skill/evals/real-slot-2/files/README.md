# 插槽 2 的素材放這裡

這三個插槽是**端到端**的測試：要從影片一路做到可以交的 kfx，所以**影片是必要的**
（前面那些小案例才是不用影片的單點測試）。

| 放什麼 | 說明 |
| --- | --- |
| 影片 | 這首 OP／ED 的片段：NCOP／NCED 最好，沒有就用正片（設計要看畫面、取幀要燒字、對位要抓音訊） |
| 歌詞 `.ass` | 日文／中文行一一對應、行的時間已經對好、逐詞 `\k` 還沒抓的那一份 |
| 參考畫面（可選） | 原片 staff 字幕那幾格的截圖，或你希望模仿的畫面 |
| 字型（可選） | 不是系統內建的字型，放一個資料夾，跑的時候用 `--font-dir` 指過去 |
| 原版手工字幕（可選） | 如果這首以前有人手做過，放進來當基準比對 |

放完之後把 `../prompt.md` 的 `<填入…>` 換掉（包含最後那行 `Input files:`），
`../case.yaml` 的 `expected_outcome` 與 `../graders/*.md` 也照這首的實際狀況調整。

注意：

- **影片檔不要跟著進版控或壓縮檔**。這個資料夾在 repo 裡是空的（只有這份說明），
  素材是在測試機上放進去的。
- 影片用得愈短愈好：只要含 OP／ED 全長即可，一兩分鐘的片段就夠，不需要整集。
- 需要音訊對位（`align.py`）的話，影片要有聲音軌；靜音的 NC 版壓製檔不行。
- 真實素材可能含有還沒公開的作品內容，放進來之前先確認可以外流。
